# mach-sdl
SDL3 bindings for the [mach](https://github.com/briar-systems/mach) programming language.


## Requirements

- A mach compiler matching the range above (`mach info` prints your version).
- The SDL3 development files, so that `libSDL3.so` (not just `libSDL3.so.0`) exists in a standard library directory such as `/usr/lib` or `/usr/lib/<arch>-linux-gnu`.
